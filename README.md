# 手札(kenko_design)

主体的健康管理のためのカード式Webアプリ(石川葵・修士研究)。

- 参加者用: https://aousa12.github.io/kenko_design/
- 研究者用(見る専用): https://aousa12.github.io/kenko_design/#view  ←参加者のバックアップコードを貼ると、その人の画面が見られます。保存・送信はされません。

## 参加者への案内(要点)
1. 上のURLを、iPhoneの「Safari」で開く。
2. 共有ボタン →「ホーム画面に追加」。
3. **ホーム画面にできたアイコンから開いて、はじめる**(Safariのままだと、記録が消えることがあります)。
4. 4日目の夜と、8日目の最後に、バックアップを送る。

## 構成
- `index.html` … アプリ本体(1ファイル)
- `manifest.webmanifest`, `icon-*.png` … ホーム画面に追加するための設定

## アプリの名前・ロゴを変えるとき
- 名前: `src/config.json` の `name` と `short_name`(ホーム画面の下に出る名前)を書き換えて、`python3 src/build.py` を実行します。
- ロゴ(ホーム画面のアイコン): `icon-180.png`(180×180)、`icon-192.png`、`icon-512.png` を差し替えます。
- 画面の中の「手札」という言葉(「手札 5枚」など)は、アプリの名前ではなく、カードの集まりを指す言葉です。名前を変えても、そのまま残ります。
- 参加者がすでに「ホーム画面に追加」したあとで名前を変えても、その人のアイコンの名前は変わりません。募集の前に決めてください。
